# Original brief (from the supplied ZIP)

- Top control: a city-name input and a submit button beside it.
- Main weather area: a circular emoji holder that changes with the current weather, followed by city name, condition, temperature, and humidity.
- Lower area: today's city air-pollution information and the previous day's pollution information, with a circular emoji indicator.
- Background palette changes according to the continent, using soft/light colors and blended transitions.
- Animated background weather emojis move along slightly inclined, gently varied paths.
- The information card blends soft blue at the top into soft orange at the bottom.
- Technology: React, Vite, Tailwind CSS, and TypeScript.

The supplied `design-reference.png` is the original hand-drawn layout.
